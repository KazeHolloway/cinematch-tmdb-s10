# CinéMatch : Catalogue de Films type TMDB

## Concept
CinéMatch est un catalogue de films permettant de découvrir les films les plus populaires du moment, de rechercher un film précis et de consulter ses détails, avec une gestion de favoris sauvegardés localement.

## Stack technique
- HTML5 / CSS3 (Grid, Flexbox)
- JavaScript (Fetch API, async/await)
- API utilisée : [TMDB API](https://www.themoviedb.org/documentation/api)

## Structure du projet
